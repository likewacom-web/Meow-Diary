เหมียวไดอารี่

รุ่นทดสอบสำหรับ Android

⬇️ ดาวน์โหลดแอป (APK)
  1. กดปุ่มด้านบนใน Chrome
  2. ถ้า Chrome ถามว่า "ไฟล์นี้อาจเป็นอันตราย" ให้กด ดาวน์โหลดต่อ / เก็บไว้
  3. กด เปิด เมื่อโหลดเสร็จ (หรือเปิดจากแอป ไฟล์ → Download)
  4. ถ้าเตือน "ไม่อนุญาตจากแหล่งนี้" → การตั้งค่า → เปิด อนุญาตจากแหล่งนี้
  5. Play Protect เตือน → ติดตั้งต่อไป
ไฟล์อัปเดตอัตโนมัติทุกครั้งที่มีรุ่นทดสอบใหม่

💻 ใช้บนคอมพิวเตอร์

เปิดเหมียวไดอารี่บนคอม
  1. เปิดลิงก์ด้านบนใน Chrome หรือ Microsoft Edge
  2. กดไอคอน ติดตั้ง (รูปจอมีลูกศร) ท้ายช่องที่อยู่เว็บ หรือ ☰ เมนูในแอป → 💻 ติดตั้งลงคอม
  3. เหมียวไดอารี่จะเปิดเป็นหน้าต่างของตัวเอง มีไอคอนบนเดสก์ท็อปและทาสก์บาร์
  4. เข้าสู่ระบบ Google บัญชีเดียวกับมือถือ โน้ตจะซิงก์กันเอง
